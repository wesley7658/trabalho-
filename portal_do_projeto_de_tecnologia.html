Modelagem de Sistemas & POO

Arquitetura de classes em Python e diagramas relacionais

Exemplo da estrutura das classes base do projeto aplicando os pilares da POO (Encapsulamento, Herança e Polimorfismo):

from abc import ABC, abstractmethod
import datetime

# Abstração & Encapsulamento
class EntidadeBase(ABC):
    def __init__(self, id_entidade: int):
        self._id = id_entidade
        self._criado_em = datetime.datetime.now()

    @property
    def id(self):
        return self._id

    @abstractmethod
    def exibir_detalhes(self) -> str:
        pass

# Herança
class Usuario(EntidadeBase):
    def __init__(self, id_entidade: int, nome: str, email: str):
        super().__init__(id_entidade)
        self.nome = nome
        self.email = email
        self.__senha_hash = ""

    # Polimorfismo
    def exibir_detalhes(self) -> str:
        return f"Usuário #{self._id}: {self.nome} ({self.email})"

Comandos & Scripts Linux (Infraestrutura)

Scripts prontos de deploy, systemd, firewall e rotinas de backup da Fase 4

Serviço Systemd (`/etc/systemd/system/meuapp.service`)

[Unit]
Description=Aplicacao Python POO - Projeto Integrador
After=network.target postgresql.service

[Service]
User=appuser
Group=appgroup
WorkingDirectory=/opt/meu_projeto
ExecStart=/opt/meu_projeto/venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

Script Shell de Backup (`backup.sh`)

#!/bin/bash
# Script de Automação de Backup do Banco e Aplicação
DATA=$(date +%Y%m%d_%H%M%S)
DESTINO="/var/backups/meuapp"
ORIGEM="/opt/meu_projeto"

mkdir -p $DESTINO
tar -czf $DESTINO/backup_app_$DATA.tar.gz $ORIGEM
echo "[$(date)] Backup concluído com sucesso." >> /var/log/meuapp_backup.log

Configuração de Firewall (UFW)

# Ativar UFW e liberar apenas portas essenciais
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp comment 'SSH'
sudo ufw allow 80/tcp comment 'HTTP Web'
sudo ufw allow 443/tcp comment 'HTTPS Safe'
sudo ufw enable
sudo ufw status verbose

Verificação de Failover / Daemon Monitor

#!/bin/bash
# Monitora se a aplicação responde HTTP 200, caso contrário reinicia o serviço
HTTP_STATUS=$(curl -o /dev/null -s -w "%{http_code}" http://localhost:8080/health)

if [ $HTTP_STATUS -ne 200 ]; then
    echo "[ALERT] Aplicação fora do ar! Reiniciando..." >> /var/log/failover.log
    systemctl restart meuapp.service
fi
